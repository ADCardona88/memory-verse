# Memory Verse App, Version One

## Goal
Help my kids memorize scripture one verse at a time. My learning goal: run the plan, build, review, and test loop myself.

## What we're building
A public web page on GitHub Pages. Progress (name, streak, history) stays only in the device's browser. Verses come from Tyndale's free NLT API. No key.

## How we know it works
Each build step has an "I'll know it works when..." sentence. Full steps live in the Google Doc until we finish rewriting them into this file.

## What we're not building
Accounts, sync across devices, multiple profiles, YouTube sermon pull, word-by-word feedback.
